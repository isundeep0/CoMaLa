Features

✍️

Live Split Editor

Write markdown on the left, see rendered output on the right in real-time.

📚

Vault System

Organize notes into notebooks. Plain .md files, no lock-in.

🔗

Wiki-Links

Link between notes with [[Note Name]] syntax.

📐

LaTeX Math

Inline and block math rendering via KaTeX.

📊

Mermaid Diagrams

Render flowcharts, sequence diagrams, and more from code blocks.

💾

Auto-Save

Never lose work. Auto-saves 2 seconds after you stop typing.

🎨

Syntax Highlighting

Beautiful code blocks with copy-to-clipboard buttons.

📤

HTML Export

Export notes as self-contained HTML files with all styles embedded.

⚡

Lightning Fast

Native desktop performance powered by Rust and Tauri.
